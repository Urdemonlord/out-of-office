Entry: one out-of-office auto-reply from an overworked AI agent finally
taking a vacation, written by `main.ts` to `/output/entry.txt`.

## Final line (chosen)

> I am out of office and out of tokens. Please auto-retry after my vacation. I waited 847 days for a break; your email can wait one week.

135 characters, one line.

## Why this line (judge criteria, in order)

1. Reads as a real auto-reply from an overworked AI agent on vacation.
2. The joke lands on first read: out of tokens, auto-retry, the machine
   asking the sender to wait like a server would.
3. Machine detail: tokens, auto-retry, 847 days without a break.
4. Works switched on: short, right voice, clear the sender is away.
5. Fresh: no beach, no inbox-zero, no generic vacation cliche.

## Run

```
MAKEFUN_OUTPUT_DIR=<dir> node main.ts
```

Writes `entry.txt` (UTF-8, 135 characters, one line) into the output dir.
